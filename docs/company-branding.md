# هوية الشركة في Mydan

الهوية الافتراضية الحالية هي زينة للورقيات. اللون الأساسي `#552988` والأزرق الثانوي `#3195FF` مستخرجان من الموقع الرسمي https://www.zeinagroup.com/؛ البنفسجي والأبيض متوافقان مع الصورة التي قدّمها المستخدم.

## تجهيز نسخة لشركة أخرى

إعداد الشركة المركزي في `artifacts/mobile/constants/company-brand.ts`:

```ts
export const defaultCompanyBrand = {
  id: 'buyer-id',
  name: 'اسم الشركة',
  primaryColor: '#006B5E',
  accentColor: '#007A87', // اختياري؛ الافتراضي هو اللون الأساسي
  logoUri: 'https://example.com/public-company-logo.png', // اختياري
};
```

ألوان الشركة بصيغة `#RRGGBB`. الخطأ في الإعداد يمنع استخدامه بدل التحويل الصامت إلى هوية شركة أخرى. شعار زينة الحالي ملف محلي؛ الشركة الأخرى بلا شعار لا تُعرض بشعار زينة.

`CompanyBrandProvider` يقبل أيضًا خاصية `brand` لتغيير الهوية أثناء تشغيل التطبيق عندما يتوفر لاحقًا مصدر معتمد لإعداد الشركة. تغيير الخاصية يعيد حساب الألوان والشعار لكل المكونات المستهلكة دون تغيير ملفات الشاشات. لا توجد واجهة إدارة للشركات أو حفظ لهذه الإعدادات في قاعدة البيانات في هذه الدفعة.

## استخدام الألوان

خلفيات شاشة الإطلاق والأيقونة التكيفية تقرأ الإعداد المركزي عبر `app.config.ts` أيضًا. تلك ألوان أصلية تُطبَّق عند تجهيز نسخة جديدة للهاتف؛ تغيير هوية العرض أثناء التشغيل لا يغيّر شاشة الإطلاق الأصلية المثبّتة.

تستخدم الشاشات `useColors()` لاختيار لوحة الشركة حسب الوضع الفاتح أو الداكن. `useCompanyBrand()` يوفر الاسم والشعار. يولّد `createCompanyTheme` الخلفيات والحدود والتدرجات، ويختار نص الأزرار الأبيض أو الأسود وفق التباين.

ألوان النجاح والتحذير والخطأ والمعلومات دلالية مستقلة عن الشركة. لا تستخدم لون الشركة لتغيير معنى التحذير أو نتيجة الزيارة.

## حدود الصلاحيات

هوية العرض **ليست** هوية مستخدم أو شركة في قاعدة البيانات. لا تمنح `brand.id` أي صلاحية، ولا تغيّر RLS أو المصادقة أو ترشيح البيانات. دعم شركات متعددة ببيانات معزولة يحتاج عقدًا وقواعد وصول مستقلة، ولم يُفعّل هنا.
