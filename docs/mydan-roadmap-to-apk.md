# مسار ميدان إلى APK

الهدف المعتمد هو Android APK للمشرفين، مع استمرار لوحة الإدارة على الويب، والاحتفاظ بكود React الحالي داخل Capacitor.

المرجع التنفيذي الحالي: [دليل بناء Android APK](mydan-android-launch-plan.md).

1. إكمال إصلاحات المهام والزيارات والأمان والمزامنة، وإبقاء ميدان مستقلًا عن Corona.
2. مراجعة توافق مخطط Supabase والخدمات مع مسودة الإصلاحات، دون تطبيق تلقائي.
3. تجهيز JDK 21 وAndroid SDK والتحقق عبر `pnpm android:doctor`.
4. استخراج APK تجريبي من المصدر عبر `pnpm apk:debug`.
5. اختبار الملف على هاتف فعلي، بما يشمل الكاميرا وGPS والدخول والمزامنة.
6. تجهيز Release بمفتاح المالك ورقم إصدار مناسب؛ اختباره ثم اعتماد التوزيع.

لا يُستخدم سكربت إعادة تغليف APK قديم. الكود والبيانات التاريخية محفوظة، والبيع والأسعار مخفيان من المنتج. بناء أصول الواجهة ليس إثباتًا على نجاح بناء أو تشغيل APK، ولا توجد آلية تحديث Android هوائية منفذة.
