# Mydan — Android Launch Plan

## 1) هدف المرحلة الحالية

تحويل التطبيق الحالي من Web PWA إلى Android APK قابل للتثبيت، مع الحفاظ على نفس النطاق الوظيفي والبيانات الحالية.

## 2) النطاق الذي سيبقى ثابتًا

- تسجيل الدخول إلى حساب المشرف
- متابعة زيارات الميدان
- مراجعة الرف
- متابعة العملاء
- متابعة الأهداف
- إشعارات داخل التطبيق
- لوحة الإدارة

## 3) ما لن يضاف

- مبيعات
- فواتير
- تحصيل
- مدفوعات
- أي ميزات مالية

## 4) الطريق العملي

### المرحلة 1: التأكد من التطبيق Web
- التطبيق يعمل محليًا
- جميع الاختبارات تنجح
- لا توجد ميزة مالية أو بيع داخل الكود

### المرحلة 2: Android packaging
- تجهيز Capacitor أو Android wrapper
- إضافة app id و package name
- إعداد ألوان التطبيق وشعار الشركة
- إعداد Screen / Splash / Icons

### المرحلة 3: التوافق مع الهاتف
- ضبط الواجهات للموبايل
- التحقق من التصفح داخل WebView
- اختبار الزيارات والمهام واللوحة الإدارية

### المرحلة 4: APK build
- بناء أول نسخة تجريبية
- تشغيلها على Emulator
- تشغيلها على هاتف فعلي
- جمع ملاحظات الأداء

## 5) أولويّات التنفيذ

1. تثبيت tooling الخاص بالـ Android
2. ربط التطبيق الحالي بالـ Android shell
3. مواءمة الأذونات الأساسية
4. اختبار التطبيق محليًا
5. بناء APK تجريبي
6. إطلاق النسخة الداخلية

## 6) الخلاصة

المشروع قابل للإنجاز بدون Replit، وباستخدام GitHub + VS Code + Android toolchain يمكن إكمال المشروع بالكامل، ثم بناء APK نهائي.
