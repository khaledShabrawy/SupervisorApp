# ميدان (Mydan) — منصة أتمتة القوى الميدانية للـ FMCG

نظام SaaS متعدد المستأجرين لأتمتة عمليات المتابعة الميدانية، مراجعة الرفوف بالذكاء الاصطناعي، وإدارة الزيارات بـ GPS.

## التقنيات

| الطبقة | التقنية |
|---|---|
| Frontend | React 18 + TypeScript + Vite + Tailwind CSS (PWA + Android APK) |
| Backend | Supabase (PostgreSQL 17, Auth, Realtime, Storage, Edge Functions) |
| ذكاء اصطناعي | Claude Vision API عبر Edge Function `analyze-shelf` |
| نشر | Cloudflare Pages — `https://mydan.digityoucan.com` |

## الوضع الراهن

- 24 جدول قاعدة بيانات + 6 views تحليلية
- 16 شاشة موبايل مكتملة + لوحة ويب للمدير
- بناء TypeScript نظيف بدون أخطاء

## الحدود الموثقة للوضع Offline

الوضع دون اتصال مدعوم للعمليات التالية:
- ✅ تسجيل الدخول والخروج للزيارات
- ✅ تحديث نتيجة الزيارة (متعامل / غير متعامل / غير موجود)
- ✅ إنجاز مهام الزيارة
- ✅ تسجيل الحضور والانصراف
- ✅ إرسال الاستبيانات الميدانية

**غير مدعوم دون اتصال:**
- ❌ إنشاء الطلبات — يتطلب اتصال بالإنترنت (تحقق من المخزون والأسعار الحية)
- ❌ مراجعة الرف بالذكاء الاصطناعي — يتطلب اتصال (استدعاء Edge Function)
- ❌ لوحة تحكم المدير — مصممة للاستخدام على الويب فقط

بمجرد استعادة الاتصال، تُرفع العمليات المحفوظة تلقائياً عبر `SyncActionBar`.

## تشغيل محلي

```bash
pnpm install
pnpm run dev        # خادم التطوير
pnpm run build      # بناء الإنتاج
```

متغيرات البيئة المطلوبة في `.env`:
```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

## الأمان

- المفتاح الوحيد في الـ frontend هو `VITE_SUPABASE_ANON_KEY` (قابل للنشر)
- لا يوجد استدعاء مباشر لـ AI APIs من الـ frontend
- عزل كامل للمستأجرين عبر `company_id` على كل query
- RLS مفعّل على جميع الجداول
